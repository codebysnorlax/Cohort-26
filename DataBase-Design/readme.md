# Database Design — ERD Collection

A collection of Entity-Relationship Diagram designs across different real-world domains. Each folder has the ERD diagram, the schema code, and a breakdown of the design decisions.

---

## Projects

| # | Project | What it models |
|---|---|---|
| 1 | [Instagram Thrift & Handmade Store](./instagram/Readme.md) | Product catalog, orders, payments, shipping for an Instagram-based shop |
| 2 | [Clinic Appointment & Diagnostics](./clinic/Readme.md) | Patient bookings, doctor consultations, lab tests, billing |
| 3 | [Smart Elevator Control System](./Elevator/Readme.md) | Building structure, elevator assignments, ride logs, maintenance |
| 4 | [Online Fitness Coaching Platform](./fitness/Readme.md) | Trainers, clients, plans, sessions, check-ins, payments |
| 5 | [Comic-Con Parking System](./parking/Readme.md) | Zones, spots, vehicles, sessions, tickets, payments |

---

## Tools used

- ERD built with **DBML / crow's foot notation**
- Diagrams exported as PNG
- Pastel color mode across all diagrams for readability

---

Each project folder contains:
- `code.txt` — the raw ERD schema
- `Readme.md` — entity breakdown, relationships, and design notes
- `*.png` — the actual ER diagram
