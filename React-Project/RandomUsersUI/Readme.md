## what you can expect from this project

 - What it does
 - Grid of user cards with avatar, name, username, location, gender badge
 - Click any card → modal with full details: email, phone, cell, age, address, timezone
 - Pagination across 250 pages (500 users total)
 - Dark/light toggle — indigo/navy theme
 - Footer with socials
