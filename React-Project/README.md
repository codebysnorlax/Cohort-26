# React Projects — Cohort 26

a collection of frontend projects built with react and vite. each one hits a different public api, has dark/light mode, and is deployed on netlify. built as part of the freeapi.app cohort curriculum.

---

## Projects

### Authentication App
full auth flow — register, login, logout, and a current user profile page. cookie-based sessions, api info panel on the left, and a netlify proxy to fix cors in production.

live — https://reactauthenticationapp.netlify.app/

---

### Meals Listing Interface
browse 290+ meals from around the world. search by name, paginate through results, and click any card to get the full recipe — ingredients, instructions, and a youtube link.

live — https://reactmealslist.netlify.app/

---

### Jokes Viewer
1465 jokes across 367 pages in a clean 2-column grid. has a category badge for explicit jokes and a dark mode that actually looks good.

live — https://reactjokesviewer.netlify.app/

---

### Product Listing Interface
e-commerce style product grid with discounted prices, rating stars, and a modal that lets you swap through product images. images fall back to a placeholder since the cdn is dead.

live — https://reactproductlistinginterface.netlify.app/

---

### Quotes Listing
300 quotes in a masonry grid with a copy-to-clipboard button on each card. uses lora serif font for that editorial feel. tags, author names, and a dark mode with purple accents.

live — https://reactquoteslisting.netlify.app/

---

### Random Cat Viewer
fetches a random cat breed and shows the image, description, temperament, and 6 trait bars. hit next to get a new one. keeps a history of the last 9 cats you have seen.

live — https://reactrandomcatviewer.netlify.app/

---

### Random Users UI
500 randomly generated user profiles in a card grid. click any card to see the full profile — email, phone, address, timezone, age. paginated across 250 pages.

live — https://reactrandomusersui.netlify.app/

---

### YouTube Videos Listing UI
youtube-style video grid with thumbnails, duration badges, view counts, and time ago. click a card to watch the video in an embedded player right in the modal.

live — https://reactyoutubevideoslistingui.netlify.app/

---

## Stack

- react 19
- vite 8
- plain css with css variables for theming
- freeapi.app for all data
- netlify for hosting
