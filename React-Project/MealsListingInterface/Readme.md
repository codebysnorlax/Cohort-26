## what you can expect from this project

- Category filter tabs (Vegetarian, Dessert, Seafood, etc.) — the API supports it
- Sort by name A–Z / Z–A
- "Back to top" button after scrolling through the grid
- Skeleton loading cards instead of plain text "Loading meals..."
- Remember last page/search on browser back (using URL params like ?page=2&q=chicken)
- Debounced search — trigger API call as user types instead of requiring Enter
- Image lazy loading is already there, but a blur placeholder while images load would feel smoother
