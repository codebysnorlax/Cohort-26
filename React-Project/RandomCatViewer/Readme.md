## Live Demo URL

https://reactrandomcatviewer.netlify.app/

## what you can expect from this project

 - Fetches a random cat breed on load from api.freeapi.app
 - Shows the cat image, name, origin, life span, description, temperament
 - Displays 6 trait bars — Adaptability, Affection, Energy, Intelligence, Kid Friendly, Dog Friendly
 - Badges for lap cat / indoor status
 - "Next Cat →" button fetches a new random breed
 - Previously seen section shows thumbnails of last 9 cats
 - Dark/light toggle with lavender/navy theme
