## what you can expect from this project

 - Sticky YouTube-style header with logo
 - Video grid with 16:9 thumbnails, duration badge, title (2-line clamp), channel, view count, time ago
 - Click card → modal with embedded YouTube player, views/likes/comments stats, description, hashtag tags
 - Helper utilities: ISO 8601 duration parser, view count formatter (1.2M / 45K), time ago
 - Pagination across 79 pages (157 videos)
 - Dark/light toggle — YouTube red theme
 - Footer with socials
