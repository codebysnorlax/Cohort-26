## Live Demo URL
https://reactproductlistinginterface.netlify.app/

## what you can expect from this project
 - Product grid — auto-fill columns, shows thumbnail, title, brand, category, discounted price, rating stars, discount badge
 - Click any card → modal with image switcher (click thumbnails to swap main image), full description, stock status, original vs discounted price
 - Dark/light toggle
 - Pagination
 - Loading/error states
