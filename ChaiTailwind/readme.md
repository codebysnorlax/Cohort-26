# ChaiTailwind

A lightweight utility-first CSS engine built with vanilla JavaScript. Part of Chai Code Cohort 26.

Live preview: [chaitailwindjs.netlify.app](https://chaitailwindjs.netlify.app/)

## What it does

ChaiTailwind scans the DOM for class names starting with `chai-`, converts them into inline styles.


## Files

- `chaiTailwind.js` — the core engine
- `index.html` — demo page built entirely using ChaiTailwind classes
